# Portfolio Acceptance & Evidence Standards

## Required portfolio evidence
1. PRD and workflow diagram.
2. Running application demo, not only static mockups.
3. Creative brief and at least four differentiated creative concepts.
4. Asset manifest with prompt/model/source/version lineage.
5. Claim registry and compliance findings with human review records.
6. Experiment plan with hypothesis, variables, guardrails, sample-size logic and stopping rule.
7. Dataset, data dictionary, deterministic calculations, test results and analysis report.
8. 3–5 minute product walkthrough and 2–3 minute analytics walkthrough.
9. Architecture, API and setup documentation.
10. Limitations and next-step roadmap.

## Evidence labels
- IMPLEMENTED: code exists and passes a reproducible test.
- TESTED: behavior verified by a named test or manual test record.
- SIMULATED: generated synthetic data; not actual media delivery.
- REAL DATA: imported from an authorized account/export with provenance.
- CONCEPT: planned but not implemented.
- HUMAN REVIEWED: named reviewer and timestamp are recorded.

## Never claim
- Real ad spend, CTR/CVR lift, ROAS, ROI, or GMV growth from synthetic rows.
- Actual customers, testimonials, influencer endorsements, or clinical proof that do not exist.
- Platform integration or auto-publishing until implemented and authorized.
- Causal impact without an appropriate experimental design.
