# AI Creative Production

Generate scripts, storyboards, shot lists, prompts and asset metadata.

## Workflow
1. Use only approved claims and authorized brand assets.
2. Produce script, shot list, on-screen text, voiceover, CTA and format specs.
3. Record provider/model, prompt, seed if available, reference assets, generation date and output URI.
4. Identify AI-generated people/voices and disclosure checks.
5. Never represent synthetic actors as actual customers or genuine testimonials.
6. Return editable production instructions, not only a final video.

## Output
asset_brief, script_version, storyboard[], prompts[], asset_manifest[], disclosure_flags[].
